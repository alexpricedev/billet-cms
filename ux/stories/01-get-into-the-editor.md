# Get into the editor

As an editor (Leo) on a phone, I want to go from the site to the editor in one move so that I can fix copy quickly.
Starting from the site's home page, signed in on the site as Leo.
Done when Leo taps Edit content, confirms the handoff and lands on the CMS dashboard.
I expect one confirm tap, no second login, and a reused or expired link to land on a page that says how to try again.
